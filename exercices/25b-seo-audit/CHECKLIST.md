# Checklist — Exercice 25b : SEO audit

- [ ] Canonical URL sur chaque page publique
- [ ] title unique < 60 chars par page
- [ ] meta description unique < 160 chars
- [ ] Open Graph tags (og:title, og:description, og:image, og:url)
- [ ] Twitter Cards (twitter:card = summary_large_image)
- [ ] noindex sur les pages privees
- [ ] JSON-LD Product sur les fiches produit
- [ ] JSON-LD BreadcrumbList
- [ ] generateMetadata() ou SeoHead component qui centralise la génération
