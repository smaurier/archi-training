# Checklist — Exercice 41 : Implémenter une CMP

- [ ] Banniere avec 3 categories (Nécessaire, Analytique, Marketing)
- [ ] Boutons : Tout accepter / Tout refuser / Personnaliser
- [ ] Accessible (ARIA, focus trap, keyboard)
- [ ] Cookie first-party pour stocker le consentement
- [ ] Duree 13 mois max
- [ ] Versioning de la politique
- [ ] Scripts charges uniquement après consentement

- [ ] Refuser aussi facile qu'accepter (même nombre de clics)
